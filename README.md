# 國文段考衝刺站 — 國一第一次段考

給女兒準備國一國文第一次段考的線上練習站。手機、平板、電腦都能用，純靜態網頁，進度存在瀏覽器裡。

**網址**：https://wenlung0090.github.io/alisa-chinese-midterm/

## 範圍
南一版第一冊 L1–L4、語文常識一（標點符號）、自學一（暑假作業）、論語第二部分。

## 功能
- ✍️ **注釋手寫練習**：老師指定的 19 則注釋（依 10/1–10/4 複習單分組）。用手指或觸控筆在手寫板上寫，寫完對答案、自己打分；不會的先描寫一次，稍後再考。有觸控筆時會自動忽略手掌。
- 🔤 字音大考驗：看國字選注音（聲調、ㄓㄗ／ㄣㄥ 陷阱）
- 🖊️ 國字手寫：看注音在田字格寫國字，答案會淡淡疊在你的字上比對
- 🔍 錯字偵探：單元卷改錯題，點出錯字
- 📝 選擇題闖關：單元卷精選＋解析，答錯自動進錯題本
- 🎁 十二樣見面禮配對、📜 論語默寫（手寫）、📚 各課重點卡
