# 國文段考衝刺站 — 國一第一次段考

給女兒準備國一國文第一次段考的線上練習站。手機、平板、電腦都能用，純靜態網頁，進度存在瀏覽器裡。

**網址**：https://wenlung0090.github.io/alisa-chinese-midterm/

## 範圍
南一版第一冊 L1–L4、語文常識一（標點符號）、自學一（暑假作業）、論語第二部分、詩詞曲五言絕句 5–8（另附 1–4 補充）。

## 功能
- ✍️ **注釋練習**：老師指定的 19 則注釋（依 10/1–10/4 複習單分組）。打字作答後對答案，會標出有打到的關鍵詞，再自己打分；不會的先照著答案打一次，稍後再考。
- 🔤 字音大考驗：看國字選注音（聲調、ㄓㄗ／ㄣㄥ 陷阱）
- 🖊️ 看注音寫國字：看注音打出國字，自動批改
- 🔍 錯字偵探：單元卷改錯題，點出錯字
- 📝 選擇題闖關：單元卷精選＋解析，答錯自動進錯題本
- 🏮 **五言絕句默寫**：整首打字默寫（逐字比對、標出錯字和漏字，可提示首字）、接下句、賞析、詩詞選擇題
- 🎁 十二樣見面禮配對、📜 論語默寫（打字、自動批改）、📚 各課重點卡
